NASDAQ Composite Prediction: A Machine Learning Analysis

A first machine-learning model: a logistic regression that predicts whether the NASDAQ Composite closes higher or lower on the next trading day.

On this page

  1. Analysis
  2. The scripts
  3. References

Analysis

This project used Python and the scikit-learn library to build a binary classification model that predicts whether the NASDAQ Composite Index will close higher or lower on the next trading day. The data came from FRED (Federal Reserve Economic Data), using the NASDAQCOM series. Although the prediction task sounds fairly simple, actually getting the model to that point took quite a few code revisions. The data had to be cleaned, sorted, and split properly before the logistic regression model could even be tested. The core question is pretty straightforward: based on today's closing value, will tomorrow be up or down? The model labelled each outcome as 1 for Higher and 0 for Lower or Equal.

The results were mixed. Accuracy and precision both sat at 58.17%. The recall came back at 100%, which sounds impressive until you see the confusion matrix. Even the F1 score looks decent at 73.55%, but the reality is that the model predicted class 1 for every single test row. It never once predicted that the NASDAQ would close lower. That likely reflects the model's reliance on a single feature, which pushed it toward always predicting the majority outcome and limited its predictive value in practice.

Ethically, this matters more than it might seem. Financial prediction tools, even simple ones built for educational purposes, carry real risk if someone were to act on their output. There is also a broader question about what data like this captures. Historical closing prices contain no information about the events, news, or external shocks that drive markets like a pandemic, a rate hike, or a geopolitical crisis. That gap between what the data shows and what drives prices is a limitation no amount of tuning is likely to fix. This baseline logistic regression model is best understood as a learning exercise, not a financial tool.

The scripts

The model was built and checked in small steps. Three of the scripts are shown here. Each reads data/NASDAQCOM_cleaned.csv, which is not published.

step_train_baseline_model.py

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

df = pd.read_csv("data/NASDAQCOM_cleaned.csv")

X = df[["NASDAQCOM"]]
y = df["target"]

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.2,
    shuffle=False
)

model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)

print("Baseline model trained successfully.")
print("Model type:", type(model).__name__)
print("Training rows:", len(X_train))
print("Test rows:", len(X_test))

step_confusion_matrix.py

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix

df = pd.read_csv("data/NASDAQCOM_cleaned.csv")

X = df[["NASDAQCOM"]]
y = df["target"]

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.2,
    shuffle=False
)

model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)

y_pred = model.predict(X_test)

cm = confusion_matrix(y_test, y_pred)

print("Confusion matrix calculated successfully.")
print("Confusion matrix:")
print(cm)

print("True Negatives:", cm[0, 0])
print("False Positives:", cm[0, 1])
print("False Negatives:", cm[1, 0])
print("True Positives:", cm[1, 1])

step_full_model_test.py

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix, precision_score, recall_score, f1_score

df = pd.read_csv("data/NASDAQCOM_cleaned.csv")

print("Dataset loaded successfully.")
print("Dataset shape:", df.shape)
print()
print("Columns:")
print(df.columns.tolist())

X = df[["NASDAQCOM"]]
y = df["target"]

print()
print("Feature matrix shape:", X.shape)
print("Target vector shape:", y.shape)

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.2,
    shuffle=False
)

print()
print("Train and test split completed.")
print("X_train shape:", X_train.shape)
print("X_test shape:", X_test.shape)
print("y_train shape:", y_train.shape)
print("y_test shape:", y_test.shape)

model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)

print()
print("Model trained successfully.")

y_pred = model.predict(X_test)

print()
print("Predictions generated successfully.")
print("First 10 predictions:")
print(y_pred[:10])

comparison_df = pd.DataFrame({
    "Actual": y_test.values,
    "Predicted": y_pred
})

print()
print("First 10 actual vs predicted rows:")
print(comparison_df.head(10))

accuracy = accuracy_score(y_test, y_pred)
cm = confusion_matrix(y_test, y_pred)

tn = cm[0, 0]
fp = cm[0, 1]
fn = cm[1, 0]
tp = cm[1, 1]

precision = precision_score(y_test, y_pred)
recall = recall_score(y_test, y_pred)
f1 = f1_score(y_test, y_pred)

print()
print("FINAL MODEL RESULTS")
print("-" * 40)
print("Accuracy:", accuracy)
print("Precision:", precision)
print("Recall:", recall)
print("F1 Score:", f1)

print()
print("Accuracy percentage:", round(accuracy * 100, 2), "%")
print("Precision percentage:", round(precision * 100, 2), "%")
print("Recall percentage:", round(recall * 100, 2), "%")
print("F1 percentage:", round(f1 * 100, 2), "%")

print()
print("Confusion Matrix Values")
print("True Negatives:", tn)
print("False Positives:", fp)
print("False Negatives:", fn)
print("True Positives:", tp)

print()
print("Interpretation")
print("This baseline logistic regression model predicted class 1 for every test row.")
print("That means it predicted the NASDAQ would close higher the next day in all test cases.")
print("The model achieved moderate accuracy, but it did not identify any class 0 cases.")
print("This shows the baseline model is too simple and likely needs more useful features.")
