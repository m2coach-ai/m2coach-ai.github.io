Recovery reporting frequency

An analysis of whether each COVID-19 India dataset row reported one or more cumulative recoveries between 30 January and 21 March 2020.

Question and method

The analysis converts the cumulative Cured value into a binary variable. Zero means that the report contained no recorded recoveries. One means that the report contained at least one recorded recovery.

covid$has_recovery <- ifelse(covid$Cured > 0, 1, 0)
frequency <- table(covid$has_recovery, useNA = "ifany")
proportion <- prop.table(frequency)

frequency
proportion

# Independent verification
sum(covid$Cured > 0)
nrow(covid)

Interpretation

Fifty-five of the 270 reports contained at least one recorded recovery. This is 20.4 percent of dataset rows. The result describes reporting rows, not individual recovery events and not an equal comparison of jurisdictions.

Judgment calls and data quality

  • The condition uses Cured > 0. A value of one and a value of nine both become one, so the binary transformation deliberately discards magnitude.
  • The cumulative value can recur across dates. Kerala's value of three appears on 19 consecutive dates, so these rows do not represent 19 separate recovery events.
  • Jurisdictions reporting on more dates contribute more rows. The proportion is weighted by filing frequency rather than equally by place.
  • The 27 raw jurisdiction labels represent 22 actual places because several names and prefixes vary.
  • Uttar Pradesh changes from five to four and then back to five. A cumulative total should not fall, so the pattern is treated as a source correction rather than a coding error.

Error and fix

An early condition used Cured == 1. It returned only 14 rows and silently excluded 41 reports containing two or more recoveries. Replacing equality with Cured > 0 aligned the code with the actual question.

Verification

The two frequencies reconcile to 270 rows. A separate calculation, sum(covid$Cured > 0), independently returns 55.

Reflection

The exercise showed that a technically correct frequency table can still support a misleading interpretation. The most important decision occurred before the table was produced: defining what a row represents. The resulting percentage is not the recovery rate. It is the proportion of reports containing a positive cumulative value.
