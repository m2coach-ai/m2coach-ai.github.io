1. The purpose of the task

The goal is not merely to make R produce numbers. The goal is to inspect how the dataset is structured, verify how R has interpreted each variable, and then calculate accurate descriptive information from the data.

Observations

Rows. In this dataset, a row is typically a state or union territory recorded on a particular date.

Variables

Columns such as date, state or territory, confirmed cases, recoveries, and deaths.

Variable class

How R stores a column, such as numeric, character, or Date. Class determines which operations are valid.

3. Install R and RStudio on your PC

Think of the two programs this way: R is the calculation engine. RStudio is the workspace where you write scripts, run R commands, inspect datasets, and view results. Install R first and RStudio second.

3.1 Install R

Open https://cran.r-project.org in a browser.
Select Download R for Windows.
Select base, which is the standard first-time installation.
Download the current Windows installer.
Run the downloaded .exe file and accept the standard settings.

3.2 Install RStudio Desktop

Open https://posit.co/downloads.
Find RStudio Desktop and choose the free open-source edition.
Download the Windows installer.
Run the installer and accept the standard settings.
Open RStudio from the Windows Start menu.

3.3 Verify the installation

In the RStudio Console, beside the > prompt, type:

R.version.string
1 + 1
Expected pattern: [1] "R version ..." [1] 2

The exact R version may differ. The important point is that both commands run without an error.

4. Create a reproducible RStudio Project

A project keeps the dataset, script, and outputs together. It also gives R a reliable working directory.

  1. In RStudio, select File > New Project.
  2. Select New Directory.
  3. Select New Project.
  4. Name it COVID19_India_Analysis.
  5. Choose a location you can find, such as Documents.
  6. Select Create Project.

Create a script with File > New File > R Script, then save it as covid_india_analysis.R.

How to run code: place the cursor on a line and press Ctrl + Enter. To run several lines, highlight them first and use the same shortcut.

5. Put the dataset in the project folder

Copy or download this file into the project folder:

6. Install packages and import the data

6.1 Install once

install.packages("readxl")

You normally install a package only once on a computer. In each new session, load it with:

library(readxl)

6.2 Preferred import for a genuine Excel file

library(readxl)

file_name <- "Covid19 India Jan 20 Mar 20.csv.xls"
covid <- read_excel(file_name)

6.3 If R says the Excel format cannot be determined

The file may actually contain comma-separated text. Try:

covid <- read.csv(
  file_name,
  stringsAsFactors = FALSE,
  check.names = FALSE
)

6.4 Automatic fallback

This version tries Excel first, then CSV if the Excel import fails:

library(readxl)

file_name <- "Covid19 India Jan 20 Mar 20.csv.xls"

covid <- tryCatch(
  read_excel(file_name),
  error = function(e) {
    message("Excel import failed; trying CSV import instead.")
    read.csv(file_name, stringsAsFactors = FALSE, check.names = FALSE)
  }
)
Checkpoint: If the import succeeds, the Environment pane should show an object called covid. Do not continue until that object exists.

total_variables <- ncol(covid)

total_observations

9. Task 1.2: Data-related information

9.1 Identify the correct columns

First print the exact names:

names(covid)

Then search for likely date and state columns:

grep("date", names(covid), ignore.case = TRUE, value = TRUE)
grep("state|territory|region", names(covid), ignore.case = TRUE, value = TRUE)

Create reusable column-name objects. If the automatic search identifies the correct names, use:

date_col <- grep("date", names(covid), ignore.case = TRUE, value = TRUE)[1]
state_col <- grep(
  "state|union.*territory|territory|region",
  names(covid),
  ignore.case = TRUE,
  value = TRUE
)[1]

date_col
state_col
Inspect the two printed names. If either is NA or incorrect, assign the exact name manually. For example: date_col <- "Date". Do not guess the name without checking names(covid).

Question 7: How many unique states or union territories?

state_values <- trimws(as.character(covid[[state_col]]))
state_values[state_values == ""] <- NA

unique_states <- sort(unique(na.omit(state_values)))
number_unique_states <- length(unique_states)

number_unique_states
unique_states

trimws() removes accidental spaces. na.omit() excludes missing labels. Printing the full list provides a second check on the count.

Question 8: What date range is covered?

First inspect the original values:

head(covid[[date_col]], 10)
class(covid[[date_col]])

If it is already a Date, use it directly:

covid_date <- covid[[date_col]]

If it is character text in day/month/year form, use:

covid_date <- as.Date(covid[[date_col]], format = "%d/%m/%Y")

If it resembles 30-01-2020, use:

covid_date <- as.Date(covid[[date_col]], format = "%d-%m-%Y")

If it resembles 2020-01-30, use:

covid_date <- as.Date(covid[[date_col]], format = "%Y-%m-%d")

For numeric Excel dates, use:

covid_date <- as.Date(as.numeric(covid[[date_col]]), origin = "1899-12-30")

Then calculate and format the range:

date_range <- range(covid_date, na.rm = TRUE)
date_range
format(date_range, "%d %B %Y")
sum(is.na(covid_date))

The missing-value count is a conversion check. If many dates became NA, stop and correct the format rather than accepting a misleading range.

Question 9: Which state appears most frequently?

state_frequency <- sort(
  table(state_values, useNA = "no"),
  decreasing = TRUE
)

head(state_frequency, 10)
most_frequent_count <- max(state_frequency)
most_frequent_states <- names(state_frequency)[
  state_frequency == most_frequent_count
]

most_frequent_states
most_frequent_count

This reports every tied state if more than one has the highest frequency. Frequency means number of rows in which a state appears, not number of COVID-19 cases.

Non-obvious point: The most frequently appearing state may simply have entered the reporting series earlier or have more dates recorded. It does not necessarily have the most cases.

10. Complete copy-ready R script

Save this in covid_india_analysis.R. Run it section by section so you can inspect intermediate results.

# ============================================================
# COVID-19 India Cases: January 2020 to March 2020
# Initial dataset exploration
# ============================================================

# 1. Install readxl once, if needed:
# install.packages("readxl")

library(readxl)

# 2. Import the file, with a CSV fallback
file_name <- "Covid19 India Jan 20 Mar 20.csv.xls"

if (!file.exists(file_name)) {
  stop("File not found. Put the dataset in the RStudio Project folder.")
}

covid <- tryCatch(
  read_excel(file_name),
  error = function(e) {
    message("Excel import failed; trying CSV import instead.")
    read.csv(file_name, stringsAsFactors = FALSE, check.names = FALSE)
  }
)

# 3. Initial exploration
class(covid)
dim(covid)
names(covid)
str(covid)
head(covid)
summary(covid)

# 4. Task 1.1
results_basic <- list(
  total_variables = ncol(covid),
  total_observations = nrow(covid),
  variable_names = names(covid),
  number_numeric = sum(sapply(covid, is.numeric)),
  numeric_variables = names(covid)[sapply(covid, is.numeric)],
  number_character = sum(sapply(covid, is.character)),
  character_variables = names(covid)[sapply(covid, is.character)],
  number_date = sum(sapply(covid, function(x) inherits(x, "Date"))),
  date_variables = names(covid)[
    sapply(covid, function(x) inherits(x, "Date"))
  ]
)

print(results_basic)

# 5. Find likely date and state columns
possible_date_columns <- grep(
  "date", names(covid), ignore.case = TRUE, value = TRUE
)
possible_state_columns <- grep(
  "state|union.*territory|territory|region",
  names(covid), ignore.case = TRUE, value = TRUE
)

possible_date_columns
possible_state_columns

if (length(possible_date_columns) == 0) {
  stop("No date column detected. Inspect names(covid) and set date_col manually.")
}
if (length(possible_state_columns) == 0) {
  stop("No state column detected. Inspect names(covid) and set state_col manually.")
}

date_col <- possible_date_columns[1]
state_col <- possible_state_columns[1]

# 6. Clean state labels
state_values <- trimws(as.character(covid[[state_col]]))
state_values[state_values == ""] <- NA

# 7. Convert the date column
raw_date <- covid[[date_col]]

if (inherits(raw_date, "Date")) {
  covid_date <- raw_date
} else if (inherits(raw_date, "POSIXt")) {
  covid_date <- as.Date(raw_date)
} else if (is.numeric(raw_date)) {
  covid_date <- as.Date(raw_date, origin = "1899-12-30")
} else {
  raw_date <- trimws(as.character(raw_date))
  candidate_formats <- c(
    "%d/%m/%Y", "%d-%m-%Y", "%Y-%m-%d",
    "%m/%d/%Y", "%d/%m/%y", "%d-%b-%Y", "%d %B %Y"
  )
  parsed_candidates <- lapply(
    candidate_formats,
    function(fmt) as.Date(raw_date, format = fmt)
  )
  successful_counts <- sapply(
    parsed_candidates,
    function(x) sum(!is.na(x))
  )
  best_format <- which.max(successful_counts)
  covid_date <- parsed_candidates[[best_format]]
  message("Selected date format: ", candidate_formats[best_format])
}

# 8. Task 1.2
unique_states <- sort(unique(na.omit(state_values)))
state_frequency <- sort(table(state_values, useNA = "no"), decreasing = TRUE)
most_frequent_count <- max(state_frequency)
most_frequent_states <- names(state_frequency)[
  state_frequency == most_frequent_count
]

results_data <- list(
  detected_state_column = state_col,
  detected_date_column = date_col,
  number_unique_states = length(unique_states),
  unique_states = unique_states,
  date_range = range(covid_date, na.rm = TRUE),
  dates_not_parsed = sum(is.na(covid_date)),
  most_frequent_state = most_frequent_states,
  appearances = most_frequent_count
)

print(results_data)

# 9. Final validation
stopifnot(nrow(covid) > 0)
stopifnot(ncol(covid) > 0)
stopifnot(length(covid_date) == nrow(covid))
stopifnot(length(state_values) == nrow(covid))

cat("\nAnalysis completed successfully.\n")

12. Troubleshooting

Error: file does not exist

list.files()
getwd()

Make sure the filename in the script exactly matches the visible filename, including spaces and extension.

Error: there is no package called readxl

install.packages("readxl")
library(readxl)

Error: path does not exist or cannot open file

Open the .Rproj file, then rerun getwd(). Avoid using a long computer-specific path if the file can simply be placed in the project folder.

Date count is zero

This can be correct at import time if the date column arrived as text. Report the imported classes for Task 1.1 unless your instructor expects cleaned classes, then separately convert the date to answer the range question. State which approach you used.

All converted dates are NA

The format string does not match the displayed values. Compare the first few raw dates with these markers:

  • %d: day
  • %m: numeric month
  • %Y: four-digit year
  • %y: two-digit year
  • %b: abbreviated month name
  • %B: full month name

State column cannot be found

names(covid)

Copy the exact name and assign it manually:

state_col <- "exact column name here"

The state count seems too high

sort(unique(state_values))
nchar(sort(unique(state_values)))

Look for spelling differences, capitalization differences, or invisible spaces. Do not merge labels unless you can defend that they refer to the same jurisdiction.

14. Connection to the learning outcome

This activity develops foundational data science practice by connecting a real dataset to mathematical and statistical structure. Counting rows and columns establishes the sample and variable dimensions. Classifying variables distinguishes quantitative measurements from categorical labels and dates. Counting unique jurisdictions and determining a date range describe coverage, while frequency tables summarize the distribution of observations across categories. These are basic but essential steps beneath later statistical modelling and AI workflows.
